The Yoga Space

The Yoga Space is a Django-based blog web application where users can create and view yoga-related blog posts. Each blog post can include a title, content, author, creation date, and banner image.

1. Features

   1. User Registration and Login
   2. User Logout
   3. Create Blog Posts
   4. View Blog Posts
   5. Upload Banner Images
   6. Display Author and Creation Date
   7. User-Specific Blog Posts
   8. Organized Blog Card Layout

2. Technologies Used

   1. Python
   2. Django
   3. HTML
   4. CSS
   5. SQLite

3. Project Overview

The Yoga Space was developed as a Django learning project. It focuses on implementing user authentication, database models, forms, templates, relationships between users and blog posts, and basic CRUD functionality.
